## HIGH

1. **Admin console is a different design language** (R-01, R-34 area). `admin/DeviceConsole.tsx` (61 raw `zinc/emerald/...` palette classes), `admin/DeviceSettings.tsx` (11), `admin/SyncStatus.tsx` (8), `LiveBoard.tsx` (27), `MyAttendanceProfile.tsx` (17), `MonthlyFingerprints.tsx` (12) use raw palette colours instead of the project tokens (`bg-card`, `text-muted-foreground`, `text-success`, ...). Dark variants exist now, but these screens will not follow a theme change.
2. **English UI text inside the Arabic workspace** (R-06 area, project rule: keep Arabic). `admin/DeviceConsole.tsx:159` "Attendance Admin", `:161` "Device Test Console", `:184` "Connection Status", `:265` "Send Raw Hex Command", placeholder `e.g., AABB1234`; `admin/AdminDashboard.tsx:270` "Audit Log". The surrounding screens are Arabic.
3. **`MyAttendanceProfile.tsx` has no error state** (R-17, R-27). Three queries (`:55`, `:59`, `:129`); only `isLoading` is handled (`:154`). If the profile query fails, `data?.linked` is falsy and the page tells the employee "حسابك غير مرتبط بسجل موظف" (`:164`), which is a wrong message for a network or server error.
4. **Icon-only buttons with no accessible name** (R-03 area, R-33). `UserMappings.tsx:125,139,155,254,268,278`: six `size="icon"` buttons (confirm, cancel, edit) with no `aria-label` or `title`. Screen readers announce "button".
5. **Placeholder used as the only label** (R-33). `RawLogs.tsx:101` and `:127` (كود الموظف), `MonthlyFingerprints.tsx:412` (رقم الموظف), `DailyView.tsx:212`, `MonthlyFingerprints.tsx:453` (كل الموظفين). The label disappears once the field has a value.
6. **LiveBoard table clips its content** (R-03, overflow hidden). `LiveBoard.tsx:465`: `overflow-hidden max-h-[380px] overflow-y-auto` with a table that has no horizontal scroll, so on a phone wide cells are cut off instead of reflowing.

## MEDIUM

7. **`prompt()` and `alert()` for input and validation** (R-20). `EmployeeDetail.tsx:1154,1276` and `ScheduleSwap.tsx:353,466` ask for the rejection note with `prompt("ملاحظة الرفض (اختياري):")`; `RawLogs.tsx:55` validates with `alert(...)`. Unstyled, not RTL-aware, and blocked in some in-app browsers. `askConfirm` already exists for yes/no; a small note dialog is missing.
8. **`ShiftManagement.tsx` drawer is not a real dialog** (R-33). The side drawer (`:205-214`) has a click scrim but no `role="dialog"`, no Escape handling and no focus trap that I could find, and slides in with `animate-in slide-in-from-left` plus `shadow-2xl` (MOTION dial is 1). The shared `Dialog`/`Sheet` component would cover all of this.
9. **Text at 11px** (R-03). Still present after the 9-10px fix: `EmployeesList.tsx:248,760,766,771,1125,1136,1146,1155` (day chips and badges), `LiveBoard.tsx:214,226,301,313`, `ShiftManagement.tsx:415,451`, `EmployeesHub.tsx:148`, `ReportsHub.tsx:131`, `PermissionReport.tsx:206`, `admin/DeviceConsole.tsx:252,340`, `admin/EmpSync.tsx:110`, `admin/SyncStatus.tsx:189`. Below the 12px floor for Arabic.
10. **`focus:ring-4` and `outline-none` on inputs** (R-34 area). `MyAttendanceProfile.tsx` (15), `ScheduleSwap.tsx` (11), `ShiftAssignments.tsx` (7), `admin/EmpSync.tsx`, `admin/SyncStatus.tsx`: a thick, off-system focus ring on form fields. Verify keyboard focus stays visible wherever `outline-none` has no replacement ring.
11. **Fixed-width controls** (R-03). `MonthlyFingerprints.tsx:412` search input `w-44`, `admin/AdminDashboard.tsx:254` `w-[160px]`, `admin/SyncStatus.tsx:254` `w-[120px]`, `DateInput` fields at `w-[11rem]` in `Permissions.tsx:174,188,300`. They should be `w-full sm:w-...` so they do not overflow a 360px phone.
12. **Mixed control heights inside one toolbar** (R-11, R-05). `Permissions.tsx:174` combines `h-11 w-[11rem]` with the surrounding `px-3 py-2` fields and `min-h-11` buttons; `UserMappings.tsx` uses `h-7 w-7` icon buttons in the table next to `h-10 w-10` in the card list. The touch rule lifts both to 44px on phones, but desktop heights drift between screens.
13. **Success feedback missing on some pages** (R-17, verify). Pages with mutations but no visible result besides a list refresh: check `Holidays.tsx`, `UserMappings.tsx`, `ManualPunches.tsx` for a toast on save. Not read in full, so marked verify.

## LOW

14. **Page titles and headers differ per screen** (R-05). The admin pages use a breadcrumb header (`DeviceConsole.tsx:157-162`) while the rest use the hub tabs; `AdminDashboard`, `SyncStatus`, `EmpSync` use `rounded-lg` cards with `focus:ring-4`, the operations pages use `rounded-xl`. Same module, three card styles.
15. **`transition-all`** (R-19). `admin/SyncStatus.tsx:105,145,215`, `admin/EmpSync.tsx:44,80`, `admin/DeviceSettings.tsx:145` animate every property, which is more than the colour change these buttons need. Use `transition-colors`.
16. **`animate-pulse` on skeletons plus `Skeleton`'s own pulse** (R-19). `MyAttendanceProfile.tsx:156-157` doubles the animation.
17. **`autoFocus` on inline edit fields** (R-33, low). `UserMappings.tsx:103,200`: fine for the inline edit, but on a phone it opens the keyboard when a row is merely toggled to edit mode. Acceptable; listed for completeness.

## Checked and clean
- Every table sits in an `overflow-x-auto` wrapper except LiveBoard (finding 6).
- Pages with queries all have loading handling; error handling is missing only in `MyAttendanceProfile.tsx` (finding 3). Pages without `onError` have no mutations.
- No gradients, no emoji, no fake data, no hover-only controls, no `div` click handlers, no ping/pulse dots, no glow, no uppercase/tracking on Arabic (audit-001 fixes hold).
- Touch targets: handled app-wide by `.attendance-touch` (44px on coarse pointers); desktop sizes remain smaller by design.
