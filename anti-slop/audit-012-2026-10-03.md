# antislop Audit 012 — Medical Sheets (2026-10-03)

**Mode:** AFTER, session override
**Scope:** sheets screens — `SheetsPage.tsx`, `ConsultantSheet.tsx` (re-export), `LasikExamSheet.tsx`, `SpecialistSheet.tsx`, `PentacamSheet.tsx`, `ui/sheet.tsx`, `SheetCenterHeader.tsx`
**Date:** 2026-10-03

## Method and boundaries

Source-level audit of the current working tree against `design.md` (blue/orange identity, shared tokens mandatory, ENERGY 1 / RHYTHM 1 / MOTION 1). No product files were changed for this audit. Priority follows the antislop tiers: HIGH = Hard Gate, MEDIUM = Purpose-Gate, LOW = Quality Locks.

Pick numbers to fix; items not mentioned stay untouched.

## Findings

### 1. HIGH — Treatment-plan table is 14 dead inputs (R-26)

`client/src/pages/LasikExamSheet.tsx:2677-2702` — every input in the "Target Refraction / Before Flap / After Flap / After Treatment / Flap Reposition / Ciclo 3x / Note" table is a bare `<input className={inp} />` with no `value`/`onChange`/state. Clinicians type, save, data is lost. Medical record: worst-case dead control.

### 2. HIGH — Fundus inputs uncontrolled (R-26)

`LasikExamSheet.tsx:2210, 2213` — same pattern in the Refraction table's Fundus row; never read, never saved.

### 3. HIGH — `readingValue` never persisted (R-26/C-2)

`LasikExamSheet.tsx:282, 2087, 2200` vs save payload at `1306-1324`. The "Reading / Add +" input renders twice (mobile + desktop) but is absent from the save payload. Silent data loss.

### 4. HIGH — `diabetesDuration` never persisted (R-26/C-2)

`LasikExamSheet.tsx:222, 1785` — "مدة الإصابة" select (shown when سكر = yes) is never saved.

### 5. HIGH — Keyboard focus invisible across most of LasikExamSheet (R-32)

`LasikExamSheet.tsx:1582, 1600, 1614, 1626, 1638, 1655, 1667` — `focus:outline-none` with static border and no focus swap (unlike `inp` at 1428 which swaps to `focus:border-[#003d9b]`). Also bare `outline-none` with no replacement at `1824, 2285, 2295, 2408, 2449, 2464, 2505, 2725, 2741`.

### 6. HIGH — No error states for ~15 data queries (R-27)

`LasikExamSheet.tsx:422-580` — no `useQuery` handles `isError`; a failed fetch renders a silently empty medical sheet. Only symptom search has loading/empty states (`2309-2320`).

### 7. HIGH — SpecialistSheet: no patient picker rendered; no loading/error UI on 10 queries (R-26/R-27)

`SpecialistSheet.tsx:11, 187-202` — `PatientPicker` imported but never rendered, so bare `/sheets/specialist` gives no path to a patient. None of the 10 queries' `isLoading`/`isError` produce UI; failure looks identical to "no data".

### 8. HIGH — WebSocket effect reconnects every render (R-35 class)

`SpecialistSheet.tsx:213-243` — effect deps are query objects (new identity each render) → teardown/reopen loop; each `onUpdate` fires 9 refetches. Functional defect behind the UI.

### 9. HIGH — Signature text below WCAG AA (R-25)

`SpecialistSheet.tsx:895` and `LasikExamSheet.tsx:2778` — `text-[#737685]` on white ≈ 4.0:1 at 12px, below the 4.5:1 floor.

### 10. MEDIUM — `uppercase tracking-[0.22em]` on Arabic labels (R-06)

`PentacamSheet.tsx:46` (`SummaryField`) — uppercase is a no-op on Arabic; letter-spacing breaks Arabic letter joining. Decorative typography that harms the script.

### 11. MEDIUM — Same "عرض JPG" capsule badge twice in one header (R-09)

`PentacamSheet.tsx:187-190` and `197-200` — duplicate badge, no added information.

### 12. MEDIUM — Decorative top background strip (R-07/design.md)

`PentacamSheet.tsx:163-168` — `aria-hidden` muted strip behind the header with no hierarchy purpose; design.md forbids decorative colored backgrounds without documented purpose.

### 13. MEDIUM — Date placeholder styled as filled text (R-23/R-38 spirit)

`LasikExamSheet.tsx:1559-1560` — `placeholder="       /       /       "` forced to full-opacity near-black (`placeholder:text-[#191c1e] placeholder:opacity-100`); an empty "تاريخ العملية" looks and prints as filled. Also a leading-space hack inside the placeholder.

### 14. MEDIUM — Symptom dropdown keyboard-inaccessible (R-32)

`LasikExamSheet.tsx:2329-2346` — option buttons use `onMouseDown` only (to beat input blur); no keyboard handler, no `role="listbox"`/aria.

### 15. MEDIUM — DB table name leaked into destructive confirm (user-copy hygiene)

`LasikExamSheet.tsx:3576` — `window.confirm("مسح شيت هذه الزيارة من sheet_entries؟")`; internal jargon in a clinician-facing dialog.

### 16. MEDIUM — Hardcoded hex palette alongside tokens (R-29/design.md)

E.g. `LasikExamSheet.tsx:1582, 2102, 2281, 2718` (`#003d9b`, `#c3c6d6`, `#f3f4f6`, `#434654`, `#737685`, `#ba1a1a`, `#f4c98a`) and `SpecialistSheet.tsx:515, 752, 837-902` — while sibling components use tokens (`text-primary`, `border`, `bg-muted`). design.md mandates shared tokens; two competing color systems in one component.

### 17. MEDIUM — "(print-only)" developer shorthand in a printed label (R-38 spirit)

`SpecialistSheet.tsx:870-871` — "Office Notes (print-only)" visible to users.

### 18. MEDIUM — Blanket `!important` reset fighting its own overrides

`SpecialistSheet.tsx:527-538` — `.specialist-sheet * { font-weight:400 !important; text-decoration:none !important }` then re-forcing `th`/table inputs to 600/700; also kills all `.border-b` inside the sheet then re-adds borders per element. Fragile print CSS.

### 19. MEDIUM — `active:scale-95` on Save (R-19/design.md)

`SpecialistSheet.tsx:722` — decorative squish on a clinical save action; design.md sets MOTION 1 (interaction feedback only), and scale can blur text on Windows at non-integer scales.

### 20. MEDIUM — `focus-visible:outline-none` on all TabsContent (R-32)

`SheetsPage.tsx:167, 176, 185, 194, 203` — removes the focus ring on tab panels with no replacement.

### 21. LOW — Print offset/scale settings with no UI on this page

`SpecialistSheet.tsx:66-69, 614` — `printOffsetXmm/printOffsetYmm/printScale` applied in the print transform but adjustable only from another page; undiscoverable here.

### 22. LOW — Sheet rendered twice (screen + print clone), `_readOnly` dead

`LasikExamSheet.tsx:1384, 3595, 3615` — `renderSheetBody(_readOnly = false)` ignores its parameter and mounts the ~1000-input sheet twice in the DOM.

### 23. LOW — Empty spacer div with stray `{" "}`

`LasikExamSheet.tsx:2521`.

### 24. LOW — Inconsistent Arabic orthography in labels

`SpecialistSheet.tsx:756-757` — "نظاره" vs "نظارة" (767) and "اشعه" vs "أشعة" (776); same concept, two spellings, duplicated across two places.

### 25. LOW — Decorative `uppercase` on bilingual labels (R-06)

`SpecialistSheet.tsx:870, 887`; `LasikExamSheet.tsx:2748, 2770` — no-op on Arabic, decorative on English.

### 26. LOW — Silent `catch {}` on sheet-content JSON.parse

`SpecialistSheet.tsx:302-345, 428-434` — corrupt saved data yields an empty form with no warning to the clinician.

### 27. LOW — English-only `sr-only` "Close" in the Sheet primitive (a11y/i18n)

`client/src/components/ui/sheet.tsx:83` — screen-reader label not localized in an Arabic-first app.
