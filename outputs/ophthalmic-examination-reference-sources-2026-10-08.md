# Ophthalmic catalog references — 2026-10-08

Research only; no database or application changes. Proposed references are clinician-review aids, not WHO-endorsed universal intervals. Generic names do not establish the device, test protocol, age, chart, or grading scale. `No universal numeric interval` is a meaningful catalog state, not a reason to invent bounds. Qualitative examples below are explicitly implementation inferences from each examination's purpose, not formally validated laboratory reference intervals.

## Source key

- IOP: [AAO EyeWiki IOP and Tonometry](https://eyewiki.aao.org/IOP_and_Tonometry); [Eye in Numbers](https://eyewiki.aao.org/Eye_in_numbers). Conventional adult IOP 10–21 mmHg; glaucoma can occur within this interval. The second source also supplies conditional pupil diameters.
- Dry eye: [AAO EyeWiki Diagnostic Testing for Dry Eye](https://eyewiki.aao.org/Diagnostic_Testing_for_Dry_Eye); [Dry Eye Syndrome](https://eyewiki.aao.org/Dry_Eye_Syndrome). Fluorescein BUT is method-sensitive, usually normal above approximately 8–10 seconds; 10 seconds is a commonly used cutoff. Schirmer varies with anesthesia and reflex stimulation. These pages do not justify generic fixed upper bounds.
- Refraction: [NEI Refractive Errors](https://www.nei.nih.gov/about/education-and-outreach/outreach-materials/refractive-errors). Errors are assessed and corrected, not classified using a universal ±4-D normal interval.
- VA: [AAO EyeWiki Visual Acuity Testing in Adults](https://eyewiki.aao.org/Visual_Acuity_Testing_in_Adults). Standard adult high-contrast benchmark 20/20; depends on correction, chart, distance, and conditions. Better acuity is possible.
- Ultrasound: [AAO EyeWiki Echography](https://eyewiki.aao.org/Echography_%28ultrasound%29). A-scan provides axial measurements; B-scan produces structural images. A device's measurable range is not a biological normal interval.
- Biometry/calculation: [ZEISS IOLMaster 500](https://www.zeiss.com/meditec/en/products/optical-biometers/iolmaster-500.html); [ZEISS Z CALC](https://zcalc.meditec.zeiss.com/). Formula, constants, individual measurements, and refractive target determine IOL power. Published device/input limits must not become normal ranges.
- Topography: [AAO EyeWiki Corneal Topography](https://eyewiki.aao.org/Corneal_Topography). Multiple maps and parameters require contextual interpretation; a color scale is not a diagnostic interval. [OCULUS Pentacam](https://www.oculus.de/en/products/pentacam/?rc=1) documents multimodal anterior-segment analysis.
- Biomechanics: [Reichert Ocular Response Analyzer](https://www.reichert.com/en/products/discontinued-ocular-response-analyzer-2nd-gen); [AAO EyeWiki Corneal Biomechanics](https://eyewiki.aao.org/Corneal_Biomechanics). CH is a dynamic measurement in mmHg; no universal interval is established by the generic name.
- Sensitivity: [AAO EyeWiki Corneal Neurotization](https://eyewiki.aao.org/Corneal_Neurotization_for_Neurotrophic_Keratitis). Cochet–Bonnet expected normal threshold at its 60-mm filament setting; not an interval valid for other instruments.
- Endothelium: [University of Iowa Corneal Imaging](https://webeye.ophth.uiowa.edu/eyeforum/tutorials/corneal-imaging/index.htm); [AAO EyeWiki Confocal Microscopy](https://eyewiki.aao.org/Confocal_Microscopy). Density and morphology depend on age and modality; averages are not universal bounds.
- Gonioscopy: [AAO EyeWiki Gonioscopy](https://eyewiki.aao.org/Gonioscopy). Shaffer grades 3–4 denote open angles; other systems use different numbering. Grade ranges are ordinal, not numeric biological intervals.
- Slit lamp/lens/lids: [AAO EyeWiki Slit Lamp Examination](https://eyewiki.aao.org/Slit_Lamp_Examination); [Blepharitis](https://eyewiki.org/Blepharitis). Systematic anatomical findings; no single normal numeric interval.
- Meibomian: [AAO EyeWiki Meibomian Gland Dysfunction](https://eyewiki.aao.org/Meibomian_Gland_Dysfunction_%28MGD%29). Assess expressibility, secretion quality, lid findings, and imaging separately. Do not use this page's inconsistent Schirmer summary to populate generic Schirmer values.
- Fundus/disc: [AAO EyeWiki Color Fundus Photography Interpretation](https://eyewiki.aao.org/Color_Fundus_Photography_Interpretation_of_Ophthalmic_Findings); [Optic Nerve Examination](https://eyewiki.aao.org/Examination_of_the_optic_nerve_at_the_slit-lamp_biomicroscope_with_a_handheld_lens). Disc size and rim are necessary context; cup/disc 0.4–0.5 is not a normal interval.
- Amsler: [AAO AMD patient resource](https://aao.org/eye-health/diseases/amd-macular-degeneration). Distortion or missing/dim areas require evaluation; a normal grid does not exclude all retinal disease.
- Color: [AAO EyeWiki Color Vision](https://eyewiki.aao.org/Color_Vision); [NIH MedlinePlus Color Vision Test](https://medlineplus.gov/ency/article/003387.htm). Interpretation depends on edition/test; no generic universal plate-count cutoff.
- Stereopsis: [AAO EyeWiki Stereopsis and Tests](https://eyewiki.aao.org/Stereopsis_and_Tests_for_Stereopsis). Performance varies with instrument, age, alignment and visual acuity.
- Contrast: [AAO EyeWiki Preoperative LASIK Evaluation](https://eyewiki.aao.org/Preoperative_Evaluation_for_LASIK_Surgery). Multiple named methods are used; generic contrast sensitivity cannot safely inherit Pelli–Robson bounds.
- Perimetry: [AAO EyeWiki Standard Automated Perimetry](https://eyewiki.aao.org/Standard_Automated_Perimetry). Age-matched instrument norms, program, reliability and pattern matter; kinetic Goldmann and Humphrey static results are not interchangeable.

## Safe implementation implications

Numeric supported candidates are adult IOP (both named entries), conditional pupil diameters, method-specific TBUT lower benchmark. Corneal sensitivity is a single method-dependent expected result, not a two-sided interval. BCVA is a chart benchmark, not a maximum. All other entries should receive explicit named qualitative/contextual references or the no-numeric-normal state. This is preferable to silently propagating unsupported legacy values. No general examination name guarantees normal findings in a particular patient, and no catalog reference is a diagnosis.
